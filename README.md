# Gravel Rush — Racing Game

A playable racing-game prototype focused on responsive dirt/gravel driving.

## Current prototype

- Top-down circuit racing
- Gravel/off-road traction differences
- Throttle, braking/reverse, steering and handbrake
- Keyboard controls
- Gamepad controls
- Touch controls for phones/tablets
- AI opponent
- Lap counting and lap timer
- Best-lap tracking for the current session
- Responsive canvas rendering

## Run it

Open `index.html` in a modern browser, or serve the repository with any static web server.

### Controls

**Keyboard**
- W / Up Arrow — throttle
- S / Down Arrow — brake / reverse
- A/D or Left/Right — steer
- Space — handbrake
- R — reset car

**Gamepad**
- RT / R2 — throttle
- LT / L2 — brake / reverse
- Left stick — steer
- A / Cross — handbrake

**Touch**
- On-screen steering, throttle, brake and handbrake buttons

## Direction

The current build is deliberately small and dependency-free so handling can be tuned before we lock in a larger engine architecture.

Planned direction includes rally-style dirt roads, asphalt, short-wheelbase cars and trucks, vehicle tuning, multiple tracks, better AI, damage, weather and first/third-person 3D driving.

See `docs/ROADMAP.md` for the development path.
